{{ 'Verification rules' if lang == 'en' else 'Doğrulama kuralları' }}

{% if lang == 'en' %}
  • Required fields: a record is not published without source URL, observation time, currency, billing unit and price dimension.
  • Negative prices are rejected. A zero price is accepted only when the source says “free”.
  • Unit is preserved: whatever unit the source gives (USD/1M tokens, USD/image, USD/request) is stored; a 1M-token equivalent is calculated separately for comparison.
  • Price history is immutable: when a price changes the old row is never deleted or updated; a new observation row is added.
  • Unapproved data is never published: records that fail verification are invisible in the UI and the API.
  • Channels are not mixed: direct provider prices and marketplace (OpenRouter) prices carry separate labels.
  • Freshness: a price older than {{ stale_days }} days is flagged as “stale” and never presented as current.
{% else %}
  • Zorunlu alanlar: kaynak URL, gözlem zamanı, para birimi, fatura birimi ve fiyat boyutu olmadan kayıt yayınlanmaz.
  • Negatif fiyat reddedilir. Sıfır fiyat yalnızca kaynakta "ücretsiz" ibaresi varsa kabul edilir.
  • Birim korunur: kaynak hangi birimi veriyorsa (USD/1M token, USD/görsel, USD/istek) o saklanır; karşılaştırma için ayrıca 1M token karşılığı hesaplanır.
  • Fiyat geçmişi değiştirilmez: fiyat değiştiğinde eski satır silinmez veya güncellenmez; yeni bir gözlem satırı eklenir.
  • Onaysız veri yayınlanmaz: doğrulama kontrolünden geçmeyen kayıt arayüzde ve API'de görünmez.
  • Kanallar karıştırılmaz: doğrudan sağlayıcı fiyatı ile pazaryeri (OpenRouter) fiyatı ayrı etiketlenir.
  • Güncellik: bir fiyat {{ stale_days }} günden eskiyse "güncelliği geçmiş" olarak işaretlenir; güncel gibi sunulmaz.
{% endif %}
