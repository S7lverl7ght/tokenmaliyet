{{ 'Why LLM bills grow without anyone noticing' if lang == 'en' else 'LLM faturası neden sessizce büyür?' }}

{% if lang == 'en' %}

Most teams that write to an AI API start with a single model and a single call pattern, and never revisit it. The bill grows in three quiet ways. First, the same long system prompt is re-sent on every request; without prompt caching you pay full input price for text the provider has already seen. Second, output is priced several times higher than input, so an assistant that rambles costs far more than one that answers in a fixed shape. Third, the model chosen for the hardest task is used for every task, including classification and extraction that a model ten times cheaper handles equally well.

None of these show up as a line item. They show up as a bill that is three to ten times higher than the work actually requires.

{% else %}

AI API'sine yazan ekiplerin çoğu tek bir modelle ve tek bir çağrı düzeniyle başlar, sonra buna bir daha bakmaz. Fatura üç sessiz yoldan büyür. Birincisi, aynı uzun sistem istemi her istekte yeniden gönderilir; prompt caching kullanılmazsa sağlayıcının zaten gördüğü metne tam girdi fiyatı ödenir. İkincisi, çıktı fiyatı girdiden birkaç kat yüksektir; bu yüzden uzun uzun konuşan bir asistan, sabit biçimde cevap veren bir asistandan çok daha pahalıdır. Üçüncüsü, en zor iş için seçilen model her işe uygulanır; sınıflandırma ve çıkarım gibi on kat ucuz bir modelin rahatça hallettiği işler de pahalı modele gider.

Bunların hiçbiri faturada ayrı kalem olarak görünmez. Görünen şey, işin gerçekte gerektirdiğinden üç–on kat yüksek bir toplam faturaldır.

{{ 'A worked example' if lang == 'en' else 'Örnek bir hesap' }}

{% if lang == 'en' %}

Take an assistant that handles 2,000 conversations a day, with 750 input and 200 output tokens per conversation. That is about 45M input and 12M output tokens a month. On a mid-tier model at $3 / 1M input and $15 / 1M output, the monthly bill is $135 + $180 = $315. Move 70% of the input into prompt caching at the cached rate and the input line falls to roughly $50, taking the bill to about $230 — before any model routing. The same arithmetic is what the public calculator on this site does; you can reproduce every number yourself.
