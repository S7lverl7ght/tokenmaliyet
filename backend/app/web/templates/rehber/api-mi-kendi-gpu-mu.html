API mi, kendi GPU'nuz mu? Başa baş noktası

Kısa cevap: aylık toplamı birkaç yüz milyon token'ın altında kalıyorsanız API neredeyse her zaman daha ucuzdur. Üstünde, kiralık GPU ciddi biçimde avantajlı hale gelir — ama yalnızca donanımı gerçekten doldurabiliyorsanız.

Karşılaştırma neden zor?

API fiyatı token, GPU fiyatı saat üzerinden ödenir. İkisini karşılaştırmak için GPU'nun saatte kaç token ürettiğini bilmeniz gerekir. Bu sayı model, niceleme (quantization), toplu iş boyutu ve donanıma göre değişir; bu yüzden aşağıdaki hesap ölçüm değil, çerçeve.

API aylık maliyet = (girdi_token/1M × girdi_fiyatı) + (çıktı_token/1M × çıktı_fiyatı)

GPU aylık maliyet = saatlik ücret × 730 × kullanım oranı

Başa baş hesabı

Bir GPU'nun saatte ürettiği token sayısı model boyutuna ve toplu iş boyutuna göre 50.000 ile 500.000 arasında değişir (7B–70B modeller, vLLM/TensorRT-LLM). Aylık 730 saatte bu, 36 milyon ile 365 milyon token demektir.

Hesabı tablodaki en ucuz GPU ile yapıyoruz ({{ gpu_samples[0].family }}):

  • {{ gpu_samples[0].family }} = {{ gpu_samples[0].price|tl_dyn }} $/saat (kesintisiz) ≈ {{ (gpu_samples[0].price * 730)|tl_dyn }} $/ay
  • Aynı parayla API'de yaklaşık {{ api_equivalent|tl_dyn }} milyon token alabilirsiniz ({{ cheapest.name }} fiyatıyla, %75 girdi / %25 çıktı varsayımı)

Yani bu GPU, ancak ayda {{ api_equivalent|tl_dyn }} milyon token'dan fazla iş yapıyorsanız (ve donanımı %70+ dolu tutabiliyorsanız) kârlı olur.

Daha güçlü bir kart (H100, B200) alırsanız saatlik ücret artar ve başa baş noktası yukarı çıkar; güncel GPU fiyatlarından kendi kartınızı seçip hesabı tekrarlayabilirsiniz.

Gizli maliyetler

GPU tarafında saatlik ücret tek kalem değildir: depolama, çıkış trafiği, model yükleme süresi, kesinti riski (spot kullanıyorsanız), mühendislik bakım süresi ve kullanılmayan kapasite. Bu site GPU fiyatlarını saatlik liste fiyatı olarak yayınlar; toplam sahip olma maliyeti bundan yüksektir.

Dürüst uyarı: Yukarıdaki token/saat aralığı sektör ortalamasıdır, bu sitede ölçülmemiştir. Kendi modelinizle gerçek ölçüm yapmadan yatırım kararı vermeyin.
