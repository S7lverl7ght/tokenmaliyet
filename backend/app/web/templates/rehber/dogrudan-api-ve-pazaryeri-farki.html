Doğrudan API ile pazaryeri fiyatı neden aynı değil?

Aynı model iki farklı yerden, iki farklı fiyatla satılabilir. Bu iki fiyatı aynı tabloda aynı satıra yazmak, karşılaştırmayı bozar. Bu yazı farkın nereden geldiğini anlatır.

İki farklı satış kanalı

Doğrudan API: Modelin sahibi (OpenAI, Anthropic, Google, DeepSeek) kendi API'sinden satar. Fiyat, sağlayıcının resmî fiyat sayfasında ilan edilir.

Pazaryeri: OpenRouter gibi aracı platformlar birçok modeli tek API altında sunar. Fiyat, platformun kendi kataloğunda yayınlanır; model sahibinin liste fiyatıyla birebir aynı olmak zorunda değildir.

Bu sitede her satırda Doğrudan API veya Pazaryeri etiketi bulunur. Varsayılan sıralama ikisini karıştırmaz; sağlayıcı filtresiyle ayırabilirsiniz.

Fark nereden gelir?

  • Platform marjı: Pazaryeri, aracılık hizmeti için fark koyabilir.
  • Varyantlar: :batch, :free gibi ekler farklı işleme biçimini (toplu işlem, ücretsiz kota) gösterir; bunlar ayrı fiyattır.
  • Yönlendirme: Pazaryeri bir isteği birden fazla sağlayıcı arasında yönlendirebilir; fiyat seçilen sağlayıcıya göre değişir.
  • Güncelleme zamanı: Platform kataloğu, sağlayıcının zamını birkaç gün gecikmeyle yansıtabilir.

Bizim kuralımız

Pazaryeri fiyatını "modelin fiyatı" diye sunmuyoruz. Fiyat tablosunda kanal sütunu, model detayında kanal bilgisi ve kaynak bağlantısı her zaman görünür. Böylece bir sayıyı görünce hangi kanaldan geldiğini bilirsiniz.
